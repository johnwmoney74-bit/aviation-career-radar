# Revision 0.2.0

## New working features

- Five career sections with editable stage labels and visible future groups.
- Nationwide/Ohio-surrounding/selected-state/approximate-distance filters; per-section filter choices remembered in the browser. These filter only work locations, never HQ or qualification fit. Distances cover a limited built-in city list and remain unknown elsewhere.
- My Opportunities, independent read/interest/progress/availability controls, notes, dated interactions, next steps and optional follow-up dates. Unread and updated-since-read indicators. Closed records are retained.
- Individual requirement comparisons, conservative automatic extraction and a simple row editor. Preferred facts do not make overall fit red. Overall green requires reviewing completeness; ambiguous requirements remain gray.
- ChatGPT profile JSON template/prompt, file drop/paste, validation, change preview, explicit approval and prior-profile restoration. Résumé uploads remain an archive, not an AI parser.
- No-link word-of-mouth leads and official-listing linking/merging with retained history. Source and opportunity entry from each section, shared employer notebooks and program reference entry.
- Single-source preview tests, staged diagnostics, customizable plain-text link rules, bounded next-page handling/extra URLs, optional detail fetches, expected sample checks, extraction review markers and recent test history. Focused export for debugging one source.
- Dated briefing snapshots, recent/pinned opportunity context, source coverage and public-page excerpts, prompt export/copy, external ChatGPT handoff and saved response import. Imported commentary never edits factual listing fields.
- Versioned migration and automatic pre-upgrade SQLite backup. Existing user data is not reseeded or cleared.

## Deliberate limits

This version keeps manual refreshes and user-added sources. It does not guarantee complete coverage, automatically discover sources, circumvent access rules, scrape authenticated Handshake/email, or support every JavaScript job site. Public pages may need per-site debugging and additional code. Lever/Greenhouse connections require their public feed URL, not an arbitrary careers landing page.

Seed program/employer facts are the earlier dated research. Page watching detects changes; human/ChatGPT research is still needed to interpret changes and confirm new factual claims. Briefings are prepared in Radar and analyzed in ChatGPT online; no subscription or AI integration is required inside Radar. Email delivery and scheduling are not included.

No resume/profile facts are sent anywhere unless you choose to share them. A briefing contains profile and opportunity notes for personalization; review the exported prompt first. Source reports omit those records but include source URLs and extracted public links.
